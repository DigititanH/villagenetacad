# App icon (meeting feedback #10)

Use the **Village NetAcad programme** mark as the Flutter launcher icon.

1. On the laptop Flutter project, place the Village NetAcad logo in `assets/branding/`.
2. Generate Android/iOS icons (e.g. `flutter_launcher_icons` pointing at that PNG).
3. Do **not** ship a generic Digititan-only glyph as the sole app icon.

Related: login screen uses a larger hero logo (`DigititanBrandHeader(hero: true)`).
