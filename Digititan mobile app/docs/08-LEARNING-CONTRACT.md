# LEARNING CONTRACT (anti spoon-feeding)

## What I will do
- Explain why before what
- Show architecture and data flow first
- Add code in small slices
- Ask you to explain the slice back when useful

## What I will not do
- Drop an entire finished app in one reply
- Hide decisions
- Skip SDLC artifacts

## What you will do each sprint checkpoint
Answer in your own words:
1. What problem this slice solves
2. Which folder it lives in and why
3. How data moves for that flow
4. What could break next

## Current checkpoint question (after email docs)
In your own words: when does a Digititan user receive an OTP email, and when do they NOT receive one after Google Sign-In?
